# История изменений

## v1.0.2

- Исправлен ввод и вывод Unicode через wide Windows API и UTF-8.
- Исправлен разбор команд с пробелами и аргументами.
- Исправлены тексты интерфейса и сообщения об ошибках.
- Команда print теперь сохраняет пробелы и Unicode-текст.
- Команда NewFile создаёт файлы с UTF-8 содержимым и Unicode-именами.
- Запуск программ переведён с system() на ShellExecuteW.
- Добавлены ANSI-цвета и единый стиль команд в нижнем регистре.
- Убрано несуществующее упоминание команды update.
- Добавлен PowerShell-установщик с пользовательским PATH.
- Добавлена автоматическая сборка Windows Release через GitHub Actions.
