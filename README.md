# MatOS-CMD

MatOS-CMD — небольшая командная строка на C++ для Windows 10/11. Программа корректно обрабатывает Unicode-ввод и вывод, включая кириллицу, иероглифы, RTL-текст, комбинируемые символы и эмодзи, насколько это поддерживает выбранный шрифт терминала.

## Команды

Команды не зависят от регистра:

- help — показать справку;
- calculate — вычислить выражение вида 5 + 3;
- print текст — вывести текст, включая пробелы и Unicode;
- newfile — создать файл с UTF-8 содержимым;
- openprogram путь — открыть программу или файл;
- version — показать версию;
- shutdown, exit или quit — завершить работу.

## Сборка

Откройте MatOS-CMD.sln в Visual Studio 2019 или новее и соберите конфигурацию Release для x64. Готовый файл обычно находится в x64/Release/Mat-CMD.exe.

## Установка и PATH

После сборки запустите PowerShell от обычного пользователя:

    powershell -ExecutionPolicy Bypass -File .\install.ps1 -ExecutablePath .\x64\Release\Mat-CMD.exe

Скрипт копирует Mat-CMD.exe в каталог пользователя и добавляет его в пользовательский PATH. Уже открытые терминалы нужно перезапустить.

## Формат релиза

В репозитории хранятся исходники и конфигурация сборки. Бинарные файлы не должны смешиваться с исходниками; их следует публиковать как артефакты GitHub Release. Версии оформляются тегами вида v1.0.2.
